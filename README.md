# Garment Edit — interactive studio

**Live site: https://yuefuturew.github.io/fabric-demo/**

Companion interactive figures for *Learning to Initialize Simulation-Based Garment Panel Editing*. The main page is one
**Garment Editing Studio**: pick a base garment (skirt / top; pants to follow), worn on the body; grab the red handle and
drag to edit it (hemline, neckline depth, sleeve length); each pose snaps to the nearest **precomputed cloth simulation**
(the browser does not simulate cloth), and the flat 2-D sewing panels on the right redraw live.

Other interactive figures (pipeline, hem predictor, per-garment viewers) are linked from the footer / [`all.html`](https://yuefuturew.github.io/fabric-demo/all.html).

Static, self-contained pages (three.js from a CDN), hosted with GitHub Pages.
